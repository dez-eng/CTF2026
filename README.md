# ⚽ 你喜欢足球吗？

## 📖 故事背景
你收到了一封神秘邮件，发件人自称是"银河战舰的守护者"。

他建立了一个私密的足球历史档案馆，里面存放着一支传奇球队的珍贵秘密。
但守护者只愿意将档案馆向"真正的追随者"开放。

你能通过考验，找到守护者心中的那支球队吗？

## 🎯 挑战目标
找到隐藏在系统中的"终极秘密"（Flag）

## 🚀 开始挑战
访问：http://localhost:8080

## 💡 提示
1. 浏览所有页面，仔细观察每个细节
2. 线索可能藏在任何地方
3. 真正的球迷知道答案，但有时候也需要一点"特殊技巧"
4. 有些秘密是伪装，真正的宝藏需要更深入的技术
